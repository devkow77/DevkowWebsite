## Uruchomienie

```bash
npm install
npm run dev
```

| Skrypt | Co robi |
| --- | --- |
| `npm run dev` | serwer deweloperski |
| `npm run build` | build produkcyjny |
| `npm run preview` | podgląd buildu |
| `npm run lint` | ESLint |
